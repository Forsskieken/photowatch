# photowatch

Takes a daily ZFS snapshot of a photo dataset, counts how many files have
disappeared since the previous snapshot, and reports that to Home Assistant —
**every day, also when nothing is gone.** That daily heartbeat is half the
point: it is how you find out when the watch itself stops running.
